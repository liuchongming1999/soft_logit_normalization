# Multiclass local dynamics checks

Run from the repository root:

```bash
python theory/verify_multiclass.py
```

The script independently checks the multiclass formulas in Section 3.8 and
Appendix A of the manuscript using float64 CPU automatic differentiation:

- class-center gradients and the radial, class-tangent and common-logit Hessian blocks;
- logarithmic derivatives of the three closed-form variance trajectories;
- covariance linearization for bounded antithetic clouds as their relative radius decreases;
- the normalized maximin exponent at fixed center losses.

The assumptions are balanced classes, regular-simplex class means, locally
concentrated populations, and direct logit gradient flow. These checks evaluate
the stated local formulas. Classification training is provided separately in `cifar/`.

The checked cases use K in {2, 3, 4, 10, 100}, gamma in {0, 0.4, 0.7, 1},
and tau in {0.2, 1}. The included `multiclass_verification.json` records 112
class-center cases. Results are regenerated by the command above.


## Full-trajectory validation and exact orbits

- [`population_flow/`](population_flow/): 240 archived cases supporting Section
  3.9 and Appendix B, including cloud-width, simplex-deformation and discrete
  GD controls. Numerical sources, initial states, time series and plotter included.
- [`binary_orbits/`](binary_orbits/): 432 exact binary-orbit checks for Appendix
  A.9, with Cartesian/polar integration and 48 symmetric second-moment checks.

Verify source/data hashes and optional selected trajectory regeneration with
`python theory/verify_archives.py --recompute-selected`. These numerical checks
are separate from the finite-network classification and representation studies.
